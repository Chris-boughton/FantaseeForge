\# Fantasee Forge



\## Data-forged fantasy football projections



Fantasee Forge is an automated NFL fantasy football analytics platform.



The project combines:

\- nflverse

\- Python

\- SQL

\- DuckDB

\- XGBoost

\- R

\- GitHub Actions

\- GitHub Pages 



\## Main features:

\- The Forge

\- Matchup Forge

\- Player Forge

\- Hot Forge

\- Cold Forge

\- Forge Lab



\## Architecture: NFL data → Parquet → DuckDB → features → model → predictions → website
